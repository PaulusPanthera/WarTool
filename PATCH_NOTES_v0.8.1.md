# WARtool v0.8.1 patch notes

## Rankings
- The result limit now offers 24, 50, 100, 250, 500, 1,000 and All.
- 100 results are shown by default.
- All has no hard cap and loads matching cards progressively while scrolling, avoiding a single 15,000-card render.

## Interface cleanup
- Shortened navigation, headings, labels and status text.
- Removed explanatory copy that repeated visible functionality.
- Moved Reset and CSV export into the filter header.
- Hid local preview/backup tools unless localhost is opened with `?preview=1`.
- Simplified the live-pipeline card and footer.
- Reduced vertical spacing on the ranking page.
- Empty catch boards now show one empty state instead of eight repeated tier messages.
- Removed the redundant selected-view KPI and repeated encounters/hour helper text.
