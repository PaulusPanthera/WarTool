# WARtool v0.8.12 — Player leaderboards and automatic context

- Adds a Players tab with separate point leaderboards for both competition teams.
- Ranks every active player by scored points, then catches, unique lines and name.
- Week defaults to the current assumed Shiny Wars week using UTC blocks: Aug 1–7, 8–14, 15–21 and 22–28.
- Time defaults to the live PokeMMO Morning/Day/Night period.
- PokeMMO time is calculated at four times real time, with the shared game-day phase anchored to UTC.
- The automatic option labels update every 15 seconds and ranking results refresh when the active period changes.
- Reset Filters returns Week and Time to their automatic modes.
