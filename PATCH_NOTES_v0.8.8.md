# WARtool v0.8.8 — species-specific Safari capture model

- Uses bundled community balls-only capture estimates for matched Johto Safari
  and Sinnoh Great Marsh species.
- Uses an editable 52% success fallback for unknown rotationals, unmatched
  species, Kanto Safari and Hoenn Safari.
- Keeps an optional global Safari catch-success override.
- Weights each Safari species independently before calculating expected
  points/hour.
- Shows weighted success/loss estimates on ranking cards and detailed
  per-species capture estimates in the calculation dialog.
- Exports Safari success, loss, model and component estimates to CSV.
- Preserves the adjustable Johto 10% and Great Marsh 20% rotational tiers.
- Keeps Safari battle-hazard and encounter-start ability warnings suppressed.
